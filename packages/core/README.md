# `@aee/core`

Core domain types, policies, orchestration, evidence correlation, and plugin contracts for [Accessibility Evidence Engine](https://github.com/Elizabeth1979/accessibility-evidence-engine).

This package is part of an early public-preview project and is not a WCAG conformance certification tool.

See the [project README](https://github.com/Elizabeth1979/accessibility-evidence-engine#readme) for status, usage, and limitations.
