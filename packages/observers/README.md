# `@aee/observers`

DOM, accessibility-tree, focus, screenshot, and privacy-sanitized network observers for [Accessibility Evidence Engine](https://github.com/Elizabeth1979/accessibility-evidence-engine).

Guidepup and axe are currently declared extension points, not implemented observers.

See the [project README](https://github.com/Elizabeth1979/accessibility-evidence-engine#readme) for the capability matrix and limitations.
