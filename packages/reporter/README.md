# `@aee/reporter`

JSON and Markdown reporters for normalized [Accessibility Evidence Engine](https://github.com/Elizabeth1979/accessibility-evidence-engine) runs, evidence, judgments, findings, and artifact references.

Reports and referenced artifacts may contain sensitive data and local filesystem paths. Review them before sharing.

See the [project README](https://github.com/Elizabeth1979/accessibility-evidence-engine#readme) for usage and limitations.
